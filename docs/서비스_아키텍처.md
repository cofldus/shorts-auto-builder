# 서비스 아키텍처

## 목표

- 키워드 입력만으로 `script.txt` 자동 생성
- 사용자 첨부 이미지/영상을 이어 붙여 쇼츠 생성
- 음성 모드 선택(`none`, `edge`, `openai`)

## 구성

- 프론트엔드: `apps/web` (Next.js, Vercel 배포)
- API 게이트웨이: `apps/web/app/api/*` (스크립트 생성, 작업 등록)
- 렌더링 워커: Python `shorts_maker` 실행 서버(Cloud Run/Render/Railway 권장)
- 저장소: S3/R2 같은 오브젝트 스토리지 권장

## 처리 흐름

1. 사용자가 주제/톤/길이를 입력하고 스크립트 자동 생성 요청
2. `/api/script`에서 스크립트를 생성해 `script.txt` 형태로 반환
3. 사용자가 이미지/영상을 첨부하고 작업 등록
4. `/api/jobs`에서 작업 ID 발급 후 워커 큐로 전달
5. 워커가 파일을 내려받아 `python -m shorts_maker` 실행
6. 결과 MP4를 저장소에 업로드하고 결과 URL 반환

## 품질 포인트

- 이미지 떨림 방지: 기본 `--image-motion none`
- 내레이션 품질: Edge 기본 + OpenAI 선택
- 안전성: 입력 검증, 실패 시 재시도, 작업 상태 추적

## 배포 메모

- Vercel 함수에서 영상 렌더링 직접 실행은 시간/메모리 제한으로 비권장
- 렌더링은 반드시 별도 워커로 분리
